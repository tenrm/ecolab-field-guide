Munsell Soil Color Charts

ชาร์ตสีดินตามระบบ Munsell 9 หน้า (10R ถึง 5Y และ Gley 1–2) แตะชิปเพื่อดูรหัสสี ค่า HEX/RGB/CIELAB และสีข้างเคียง หรือเทียบสีจากรูปถ่ายดินในส่วนด้านล่าง

หมายเหตุ: การตรวจสอบนี้ เป็นไปเพื่อการฝึกเท่านั้น เนื่องจากสีบนจอคำนวณจากข้อมูล Munsell Renotation (1943) ภายใต้แหล่งแสง C แปลงเป็น sRGB ด้วย Bradford adaptation ค่า Value 2.5 ได้จากการประมาณค่าระหว่างแถว ชิปที่อยู่นอกขอบเขตสี sRGB ถูกเว้นว่างไว้ สีที่เห็นขึ้นกับจอและการตั้งค่าความสว่าง ชิปในหน้านี้จึงใช้ศึกษาและอ้างอิงได้ แต่ใช้แทนชาร์ตกระดาษจริงในการบรรยายดินอย่างเป็นทางการไม่ได้ รูปถ่ายจากกล้องมือถือมี white balance ที่คลาดเคลื่อน ผลการเทียบจากรูปจึงเป็นค่าประมาณเท่านั้น

อ่านรหัสอย่างไร

10YR 4/3 คือ Hue 10YR, Value 4, Chroma 3

  • Hue โทนสีหลัก R = แดง, YR = เหลืองแดง, Y = เหลือง
  • Value ความสว่าง 0 (ดำ) ถึง 10 (ขาว)
  • Chroma ความอิ่มตัว ยิ่งมากยิ่งสด 0 = สีเทากลาง

การเทียบสีในสนาม

  • บันทึกทั้งสภาพ ชื้น (moist) และ แห้ง (dry) แยกกัน
  • ใช้แสงแดดธรรมชาติ หลีกเลี่ยงช่วงเช้าตรู่/เย็นและแดดจัดตรง
  • ถ้าสีอยู่ระหว่างชิป ให้เลือกชิปที่ใกล้ที่สุด ไม่ปัดเป็นทศนิยมเอง
  • ใช้ชิปที่ตรงกับดินที่บี้แล้ว (crushed) และผิวก้อน (ped face) ตามที่ต้องการบันทึก

หน้า Gley

ใช้กับดินที่ขาดออกซิเจนจากการแช่ขังน้ำนาน มีสีเทา เขียว หรือฟ้าอมเทา สีกลาง (neutral) เขียนเป็น N 5/ โดยไม่มีค่า Chroma

Gley 1 = N, 10Y–5G · Gley 2 = 10G–5PB
